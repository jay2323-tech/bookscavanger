# BookScavenger P3 — platform scale

## BS-040 Meilisearch (Phase 1 — local ready)

### Local (Homebrew — no Docker needed)

```bash
# Homebrew Meilisearch (no Docker)
brew install meilisearch
mkdir -p .meili-data/data.ms
meilisearch \
  --db-path .meili-data/data.ms \
  --http-addr 127.0.0.1:7700 \
  --env development \
  --master-key dev-master-key-bookscavenger \
  --no-analytics
```

Or Docker:

```bash
docker compose up -d meilisearch
```

Backend `backend/.env`:

```
MEILI_HOST=http://127.0.0.1:7700
MEILI_API_KEY=dev-master-key-bookscavenger
MEILI_INDEX=books
```

Restart the API. On boot it warm-indexes when the Meili index is empty.

Manual reindex:

```bash
cd backend && npm run meili-sync
```

Or admin JWT:

```bash
curl -X POST "$BACKEND/api/admin/meili-sync" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

If `MEILI_HOST` is unset, search keeps using Supabase + `pg_trgm`.

### Production (Render)

Add a Meilisearch service (or [Meilisearch Cloud](https://www.meilisearch.com/cloud)), set `MEILI_HOST` / `MEILI_API_KEY` on the API, then run meili-sync once.

## Search popularity (Phase 1)

Run `database/migrations/009_search_popularity.sql` in Supabase.

Ranking reads the precomputed `search_popularity` table (5‑minute memory TTL) instead of scanning ~800 analytics rows per “best” sort. Each search bumps the count via `bump_search_popularity`.

## BS-041 Rate limits + cache

Public book routes: **90 req / IP / minute** (`429` when exceeded).

Search responses: in-memory TTL ~30s + `Cache-Control: public, s-maxage=30`. Header `X-Cache: HIT|MISS`.

## BS-043 ILS / Koha sync

Librarian endpoint:

`POST /api/library/ils/sync`

```json
{
  "type": "koha_csv",
  "endpoint": "https://your-library.example/export.csv",
  "replace": false
}
```

or

```json
{
  "type": "koha_sru",
  "endpoint": "https://your-koha.example/cgi-bin/koha/svc/server",
  "query": "dc.title=habits",
  "replace": true
}
```

CSV columns: `title` (required), `author`, `isbn`, `available`/`status`.

`replace: true` deletes that library’s current books before insert.
