## BS-040 Meilisearch (deferred — do later)

Search keeps using **Supabase** until you set `MEILI_HOST`. Nothing to run now.

When you want it:

```bash
docker compose up -d meilisearch
```

Backend env:

```
MEILI_HOST=http://127.0.0.1:7700
# MEILI_API_KEY=...   # if you set MEILI_MASTER_KEY
MEILI_INDEX=books
```

Reindex (admin JWT):

```bash
curl -X POST "$BACKEND/api/admin/meili-sync" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

If `MEILI_HOST` is unset, search keeps using Supabase (current behavior).

On Render: add a Meilisearch service (or Meilisearch Cloud), then set `MEILI_HOST` / `MEILI_API_KEY` on the API service and run meili-sync once.

## BS-041 Rate limits + cache

Public book routes: **90 req / IP / minute** (`429` when exceeded).

Search responses: in-memory TTL ~30s + `Cache-Control: public, s-maxage=30`. Header `X-Cache: HIT|MISS`.

## BS-043 ILS / Koha sync

Librarian endpoint:

`POST /api/library/ils/sync`

```json
{
  "type": "koha_csv",
  "endpoint": "https://your-library.example/export.csv",
  "replace": false
}
```

or

```json
{
  "type": "koha_sru",
  "endpoint": "https://your-koha.example/cgi-bin/koha/svc/server",
  "query": "dc.title=habits",
  "replace": true
}
```

CSV columns: `title` (required), `author`, `isbn`, `available`/`status`.

`replace: true` deletes that library’s current books before insert.
